Start your own FDP ecosystem

A FAIR Data Point that describes every way to get each resource (portals, APIs, SPARQL endpoints, dumps, cloud buckets, copies in aggregators), served from a GitHub repository. No server, and free for public repositories.

Use the template → See the demo

Three steps

From nothing to a live, validated, FAIR-assessed FDP in a few minutes.

1

Create your repository

Use the template to create a public repository from StaticFDP/fdp-ecosystem-template.

2

Switch on GitHub Pages

In the new repository: Settings → Pages → Source: GitHub Actions. Then run Actions → Deploy viewer to GitHub Pages. The first deploy points the configuration and every IRI at your repository.

3

Make it yours

Edit fdp.config.json (name, headline, colours, fonts, maintainer) and assets/logo.svg. Replace the example source, then add sources through the Add a data source issue form. Optionally register your FDP in the FDP Index.

What every ecosystem gets

A website from TurtleIndex → catalog → dataset → ways to get it, with search, access-method filters, and light and dark mode. Static HTML and schema.org JSON-LD for search engines.
Every way to get the dataEach distribution is typed with an access method (SPARQL, REST, dump, cloud bucket, aggregator copy, …) and has a "How to get it" recipe.
Live FAIR Data PointsLink someone else's FDP; the site crawls it in the browser and stays current.
Self-service contributionsAn issue form becomes a validated pull request. No Turtle needed.
Contributor creditFrom commits, pull requests and form submissions, with names, Wikidata items and ORCID iDs from Wikidata (P2037). Published in RDF too.
FAIR assessmentWalks every level of the FDP and runs the OSTrails FAIR Champion tests: weekly, after deploys and on demand.
ValidationEvery push checks the Turtle syntax, the DCAT shape, the vocabulary terms and the consistency of the index.
Engine updatesYour content stays yours; template improvements arrive as a pull request.

Make it discoverable

Register your ecosystem's index in the FDP Index by adding it to registry.yaml. For persistent identifiers, register a w3id and run scripts/set-base.sh https://w3id.org/<your-id>/.
