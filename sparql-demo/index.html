How this works

  1. Each registered FDP publishes a catalog.ttl file served via GitHub Pages — no server needed.
  2. Comunica (comunica.dev) is a standards-compliant SPARQL engine that runs entirely in your browser using Web Workers.
  3. When you click Run query, Comunica fetches the listed Turtle files over HTTP, builds an in-memory RDF dataset, and evaluates your SPARQL SELECT or CONSTRUCT.
  4. Results are rendered by YASR as a sortable table. You can also view raw JSON, pivot charts, or download as CSV.
  5. You can edit the query freely — it is plain SPARQL 1.1. The SERVICE keyword lets you federate against external SPARQL endpoints too.
